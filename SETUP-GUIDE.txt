MONEY TRACKER - SETUP GUIDE (v3)
================================

FILES
- index.html, sw.js, manifest.json, icon-192.png, icon-512.png  -> the app (upload all together)
- Code.gs                                                        -> Google Sheets cloud sync (optional)

UPDATING FROM AN OLD VERSION
- Replace the old files with these new ones (same link). Your data stays.
- If the phone still shows the old version, close the app and open it again.


STEP 1 - PUT THE APP ONLINE (free)
----------------------------------
GitHub Pages:
1. Create a free account at github.com
2. New repository (example: money-tracker), Public
3. "Add file" > "Upload files" > upload the 5 app files > Commit
4. Settings > Pages > Source: Deploy from a branch > main / (root) > Save
5. After 1-2 minutes: https://YOUR-USERNAME.github.io/money-tracker/

Quick PC test only: double-click index.html (data stays in that browser only).


STEP 2 - INSTALL ON SAMSUNG A35 / PC
------------------------------------
Phone: open the link in Chrome > menu (3 dots) > Add to Home screen / Install app.
PC: open the link in Chrome/Edge > click the install icon in the address bar.


STEP 3 - CLOUD SYNC WITH GOOGLE SHEETS
--------------------------------------
1. sheets.google.com > blank spreadsheet (name: Money Tracker)
2. Extensions > Apps Script > delete sample code > paste Code.gs
3. Change SECRET_KEY to your own secret > Save
4. Deploy > New deployment > Web app
     Execute as: Me | Who has access: Anyone > Deploy > Authorize access
5. Copy the Web App URL (ends with /exec)
6. In the app: Settings > Cloud sync > paste URL + same secret key > Save settings
7. Do step 6 on your other device.
- Tabs in the Sheet: Summary, Transactions, Accounts, Debts, Debt Schedule.
- Do not edit or delete the hidden "_data" tab.


THEME & COLORS
--------------
Settings (gear icon) > Theme & colors
- Background: Auto (follows phone), Light, Soft grey, Warm white, Dim, Dark grey, Black.
- Main color: Charcoal, Graphite, Grey, Steel, Slate, Navy, Teal, Plum, Silver,
  or tap the paint icon to pick any color.
- Changes apply right away and are synced to your other devices.
- Red = money out, Green = money in (always).


DEBTS & LOANS WITH DIFFERENT AMOUNTS PER MONTH
----------------------------------------------
Example: SPayLater = 2,000 this month, 1,000 next month.

New loan:
1. Debt page > + Add > choose Type (SPayLater, Pag-IBIG Loan, SSS Loan, etc.)
2. Enter Total amount, Payment schedule (Monthly, Yearly, etc.), Due date.
3. Check "Amount is different per month / period".
4. Tap "Save & set amounts per period".
5. Type the amount for each month (e.g., Nov 2,000 / Dec 1,000).
   - Blank = uses the usual amount.
   - 0 = no payment that month.
   - "Fill blanks" = puts one amount on all empty future months.
   - The box at the bottom tells you if the plan matches your remaining debt.

Existing loan:
- Tap the loan > "Amount per month" button > edit the amounts > Save.

New SPayLater order:
- Tap the loan > "+ Add amount" > enter the new order amount > Save.
  It opens the monthly amounts next, so you can update each month right away.

Pay:
- Tap the loan > Pay. It pre-fills the exact amount due for this month.

Dashboard:
- Dues this month = total of all loan payments due this month (uses your exact amounts).
- Still unpaid = how much you still need to pay this period.
- Each loan shows: Due / Overdue (red) / Paid this period + next due and amount.


KEEPING YOUR DATA SAFE
----------------------
- Data is never deleted unless YOU delete it (Erase all data needs you to type DELETE).
- Do not clear browser/site data for the app. If it happens, cloud sync restores everything.
- Settings > Export backup (JSON) / Import backup. Export to Excel (CSV) is also available.
