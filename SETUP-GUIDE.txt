MONEY TRACKER - SETUP GUIDE (v5)
================================

FILES
- index.html, sw.js, manifest.json, icon-192.png, icon-512.png  -> the app (upload all together)
- Code.gs                                                        -> Google Sheets cloud sync (optional)

UPDATING FROM AN OLD VERSION
- Replace the old files with these new ones (same link). Your data stays.
- If the phone still shows the old version, close the app and open it again.


WHAT'S NEW IN v5
----------------
1. "Show more" in History now works.
   - It only appears when there are more items, and shows how many are left.
2. Dashboard now shows CURRENT BALANCE = the real money left in your Cash + Banks + E-wallets.
   - Breakdown: Cash / Banks / E-wallets. Savings, Debt and Net worth are below it.
   - Loans are NOT counted as your money. They only show as Debt.
3. "Update balances" button (on the dashboard card):
   - Type the actual amount in each account (check your GCash/bank app and your wallet).
   - The app fixes the difference and saves it as "Balance update" in History.
   - Balance updates are NOT counted as income or expense.
   - You can also fix one account: Accounts > ⋯ > Current balance.
4. Loans no longer add money to your balance by default.
   - Only check "Add the loan money to my account balance" if the money just came in
     and is still in that account.
   - Old loans that added money: open the loan > Edit loan > check
     "Remove the loan money from ..." > Save.


STEP 1 - PUT THE APP ONLINE (free)
----------------------------------
1. Create a free account at github.com
2. New repository (example: money-tracker), Public
3. "Add file" > "Upload files" > upload the 5 app files > Commit
4. Settings > Pages > Source: Deploy from a branch > main / (root) > Save
5. After 1-2 minutes: https://YOUR-USERNAME.github.io/money-tracker/


STEP 2 - INSTALL ON SAMSUNG A35 / PC
------------------------------------
Phone: open the link in Chrome > menu (3 dots) > Add to Home screen / Install app.
PC: open the link in Chrome/Edge > click the install icon in the address bar.


STEP 3 - CLOUD SYNC WITH GOOGLE SHEETS
--------------------------------------
1. sheets.google.com > blank spreadsheet (name: Money Tracker)
2. Extensions > Apps Script > delete sample code > paste Code.gs
3. Change SECRET_KEY to your own secret > Save
4. Deploy > New deployment > Web app
     Execute as: Me | Who has access: Anyone > Deploy > Authorize access
5. Copy the Web App URL (ends with /exec)
6. In the app: Settings > Cloud sync > paste URL + same secret key > Save settings
7. Do step 6 on your other device.
- Do not edit or delete the hidden "_data" tab.


LOANS
-----
- Add: Debt page > + Add > Type, Total, Schedule, First due date, Last payment month.
- Different amount per month: check the box, then type each month's amount.
- Fix mistakes: tap any item in the loan History to edit or delete it.


KEEPING YOUR DATA SAFE
----------------------
- Data is never deleted unless YOU delete it (Erase all data needs you to type DELETE).
- Settings > Export backup (JSON) / Import backup. Export to Excel (CSV) is also available.
